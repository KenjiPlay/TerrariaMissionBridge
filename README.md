# TerrariaMissionBridge

Plugin de TShock para conectar entregas de items de Terraria con misiones de un bot de Discord.

## Comandos

- `/discord <idDiscord>`: vincula tu personaje con Discord.
- `/entregar`: entrega el item de la mano si coincide con una misión.
- `/mbitem`: muestra el ID del item en la mano.
- `/mbreload`: recarga archivos de configuración.

## Archivos

El plugin crea/usa una carpeta:

`tshock/TerrariaMissionBridge/`

Con:

- `config.txt`
- `profiles.txt`
- `missions.txt`
- `players.txt`
